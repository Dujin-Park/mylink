# mylink

마이링크는 Next.js App Router와 TypeScript를 사용하는 웹 프로젝트입니다.

## 시작하기

개발 서버를 실행합니다.

```bash
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 열어 확인하세요.

첫 화면은 `src/app/page.tsx`에서 수정할 수 있습니다. 공통 레이아웃과 페이지 메타데이터는 `src/app/layout.tsx`에서 관리합니다.

## 사용 가능한 명령

- `npm run dev` — 개발 서버 실행
- `npm run build` — 프로덕션 빌드
- `npm run start` — 프로덕션 서버 실행
- `npm run lint` — ESLint 검사
